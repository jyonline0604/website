# ⚙️ 批量生成流程設計

> 創作日期：2026-04-26
> 目的：建立自動化每日出文系統

---

## 一、現有腳本工具

| 腳本 | 功能 |
|------|------|
| `novel_generator_multimodel.py` | 多模型章節生成 |
| `batch_generator_v2.py` | 批量生成 |
| `expand_chapters_batch.py` | 章節擴展 |
| `update_novel_lists.py` | 更新目錄 |

---

## 二、每日生成流程（建議）

### 每日任務流程

```
00:05 — 每日備份腳本運行
   └── 備份 workspace 到 Max-backup

07:00 — 小說章節生成
   └── 生成 3 章（可調整數量）
   └── 自動檢查標題唯一性
   └── 自動檢查HTML結構

07:30 — 章節品質檢查
   └── HTML拼接完整性
   └── 標題格式
   └── 標點符號

08:00 — 推送到 GitHub
   └── 推送 research/ 章節草稿
   └── 推送 my-novel-website/

12:00 — 可選：根據反饋調整
```

---

## 三、批量生成命令

### 單章生成
```bash
python3 scripts/novel_generator_multimodel.py \
  --count 1 \
  --title "第XXX章 章節名"
```

### 批量生成（每日3章）
```bash
# 每日 cron 任務
python3 scripts/novel_generator_multimodel.py \
  --count 3 \
  --start-chapter XXX \
  --model deepseek
```

### 章節擴展
```bash
python3 scripts/expand_chapters_batch.py \
  --start 1 \
  --end 200
```

## 四、品質控制清單

### 生成前
- [ ] 確認章節編號
- [ ] 確認標題不重複
- [ ] 確認大綱進度

### 生成後
- [ ] 檢查HTML只有1個`<html>`
- [ ] 檢查只有1個`<h1>`
- [ ] 檢查標題格式正確
- [ ] 更新 chapters.html

### 發布後
- [ ] 檢查網站顯示正確
- [ ] 確認章節連結有效
