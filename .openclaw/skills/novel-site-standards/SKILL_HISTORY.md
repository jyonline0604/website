## [2026-04-28] 更新 (v2.9.19) - 章節標題顯示機制優化

### 問題根本原因
txt源文件中，系統用來識別章節標題的**正則表達式**要求標題行必須以 `# ` 開頭：

```python
# 錯誤示範（無 # 前綴）
第211章 · 銀白色蛻變

# 正確格式（有 # 前綴）
# 第211章 · 銀白色蛻變
```

### 預防機制
在處理新上傳的txt文件時，必須先檢查並修復標題行格式：

```python
def extract_title(content):
    """提取章節標題（支援 # 前綴）"""
    for line in content.strip().split('\n'):
        if line.startswith('# '):
            m = re.search(r'第[零一二三四五六七八九十百千萬\d]+章\s*[·:：]\s*(.+)', line)
            if m:
                return m.group(1).strip()
        # 向後兼容：也支持沒有 # 前綴的標題
        elif re.match(r'^第[零一二三四五六七八九十百千萬\d]+章\s*[·:：]', line):
            m = re.search(r'第[零一二三四五六七八九十百千萬\d]+章\s*[·:：]\s*(.+)', line)
            if m:
                return m.group(1).strip()
    return None
```

### 自動修復腳本
```bash
# 檢查並自動修復所有txt文件的標題前綴
for f in /home/openclaw/.openclaw/media/inbound/第*.txt; do
    first=$(head -1 "$f")
    ch_num=$(echo "$first" | grep -oP '第\d+章')
    if [ -n "$ch_num" ] && [[ ! "$first" =~ ^# ]]; then
        sed -i "1s/^/${ch_num} · /" "$f"
        echo "Fixed: $f"
    fi
done
```

# 修復前

## [2026-05-04] 更新 (v2.9.53) - CH321-340 段落結構修復

### 問題描述
大肥喵上傳 CH321-340 的txt文件後，生成的HTML顯示為「一堆字沒有任何分段」。

### 根本原因
1. **txt文件格式**：txt使用雙換行 `\n\n` 分隔段落
2. **錯誤的處理方式**：之前直接用 `\n\n` 連接內容放入 `<main>`，但瀏覽器渲染時會忽略純文本中的換行
3. **解決方法**：每個段落必須用 `<p>` 標籤包裹

### 正確處理流程

#### 1. 讀取txt文件
```python
lines = content.split('\n')
# 第一行是標題行，第2行開始是內容
```

#### 2. 提取標題
```python
match = re.match(r'^第[零一二三四五六七八九十百千萬\d]+章\s+(.*)$', title_line)
chapter_title = match.group(1).strip() if match else title_line
```

#### 3. 收集段落（按雙換行分隔）
```python
paragraphs = []
current = []
for line in lines[1:]:  # 跳過標題行
    stripped = line.strip()
    if not stripped:  # 空行 = 段落分隔符
        if current:
            paragraphs.append('\n'.join(current))
            current = []
    else:
        current.append(line)
if current:
    paragraphs.append('\n'.join(current))
```

#### 4. 用 `<p>` 標籤包裹每個段落
```python
body_parts = []
for para in paragraphs:
    para = convert_text(para)  # 簡體→繁體
    body_parts.append(f'<p>{para}</p>')
body = '\n'.join(body_parts)
```

#### 5. 生成HTML時替換
```html
<main>
{content}  <!-- 這裡是帶<p>標籤的內容 -->
</main>
```

### 🚨 重要提醒：段落格式規則

**txt文件 → HTML 的正確轉換：**

| txt格式 | HTML格式 |
|---------|----------|
| 雙換行 `\n\n` | `<p>段落1</p><p>段落2</p>` |
| 單換行 `\n` | 同一段落內的換行（不產生新段落） |

**❌ 錯誤做法：**
```python
# 錯誤：直接用雙換行連接，瀏覽器會忽略換行
body = '\n\n'.join(paragraphs)  # 錯誤！
```

**✅ 正確做法：**
```python
# 正確：用<p>標籤包裹每個段落
body = ''.join(f'<p>{p}</p>' for p in paragraphs)
```

**為什麼要用 `<p>` 標籤？**
- 瀏覽器會將 `<p>` 元素自動渲染為 block 級別，各段落自動換行
- 純文本中的 `\n\n` 在 HTML 中不會產生視覺換行效果
- 這是 HTML 標準的段落表示方式
