隱私權政策

最後更新日期：2026-07-08

1. 資料收集

本網站（kofhk.com）運作時可能收集以下資訊：

  • 聊天記錄：當您使用 AI 聊天功能（小肥喵助手）時，您輸入的訊息會傳送至第三方 AI 服務提供商（OpenRouter）以生成回覆。我們不會在伺服器端永久儲存聊天內容。
  • 技術日誌：Cloudflare 會自動記錄標準的存取日誌（IP 地址、瀏覽器類型、請求時間等），用於網站安全和效能監控。
  • Cookie 與本地儲存：網站使用瀏覽器本地儲存（localStorage）來保存您的閱讀偏好（如字型大小、主題顏色）。這些資料不會上傳至伺服器。

2. 資料使用方式

  • 聊天訊息僅用於即時生成 AI 回覆，傳輸過程經由 Cloudflare Workers 代理。
  • 技術日誌用於安全防護（DDoS 防禦、濫用偵測）和網站流量分析。
  • 閱讀偏好僅存於您的瀏覽器中，用於改善閱讀體驗。

3. 第三方服務

本網站依賴以下第三方服務：

  • OpenRouter — AI 聊天功能的模型提供商，訊息內容會傳送至其 API 進行處理。
  • Cloudflare — CDN 與安全防護服務，所有網站流量皆經過其網絡。
  • GitHub Pages — 靜態網頁託管平台。

這些第三方服務有其獨立的隱私權政策，建議您查閱相關文件。

4. 資料保護

本網站採取以下措施保護您的資料：

  • 全站強制 HTTPS 加密傳輸（HSTS）
  • 內容安全政策（CSP）防止跨站腳本攻擊
  • 聊天端點設有速率限制，防止濫用
  • 不會出售、出租或分享您的個人資料給第三方

5. 您的權利

根據適用的隱私法規，您有權：

  • 查詢我們持有您的哪些資料
  • 要求刪除您的資料
  • 反對或限制資料處理
  • 提出投訴

如需行使上述權利，請透過 GitHub Issues 聯絡我們（見下方）。

6. 聯絡方式

如對本隱私權政策有任何疑問，請透過以下方式聯絡：

  • GitHub：github.com/jyonline0604/website
  • 本網站聊天功能中的「小肥喵」助手亦可協助回答基本問題
