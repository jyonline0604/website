## 小境界（每大境8個）

| 序號 | 名稱 | 說明 |
|:--:|------|------|
| 1 | 前期 | 初入門道，剛觸碰該境界靈力 |
| 2 | 前期巔峰 | 前期頂點，差一線入中 |
| 3 | 中期 | 已穩固掌握，開始應用於實戰 |
| 4 | 中期巔峰 | 中期頂點，壓迫感明顯 |
| 5 | 後期 | 力量豐沛，可對抗同階強者 |
| 6 | 後期巔峰 | 該境極限，觸碰下一境的門檻 |
| 7 | 半步（巔） | 跨出第一步但未完全踏入下一大境——跨境門檻狀態 |
| 8 | 圓滿 → 突破 | 小境界徹底圓滿，找到契機跨入下一大境界 |

### 境界表示範例

```
煉魂前期 → 煉魂前期巔峰 → 煉魂中期 → 煉魂中期巔峰 → 
煉魂後期 → 煉魂後期巔峰 → 煉魂半步（巔） → 煉魂圓滿 → 突破 →
凝神前期
```
