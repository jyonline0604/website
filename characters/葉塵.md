## 身形與氣質

- **身形**：修長、清瘦，但不單薄
- **眼神**：漆黑深邃，帶有輪迴的厚重感
- **氣場安靜**：多數時候沉靜內斂，戰鬥時才顯露鋒芒
- **容顏**：年輕但眼神超出年齡的深邃，有種不屬於少年的沉穩

---

## 髮型與衣著

### 日常服飾（青雲宗修士袍）

- 白底藍紋的修士袍
- 領口與袖口有淡藍色靈紋滾邊
- 腰間束一條同色腰帶，掛有身份令牌
- 長髮通常自然垂落，或以簡單髮帶束起
- 衣袖略寬，適合施展法術

### 戰鬥模式

- 修士袍衣襟微敞
- 體表有淡金色元氣光環流轉
- 塵淵劍出鞘時劍身散發銀白光芒
- 眼神銳利，氣勢瞬間壓制全場

### 低谷期（感氣三年失敗 — 廢物期）

- 破舊灰色布衣，縫補痕跡明顯
- 臉色蒼白、身形消瘦
- 眼神暗淡，常帶疲態
- 頭髮散亂無光澤

### 輪迴虛空形態（識海深處）

- 葉塵本體化為金色光影
- 周圍九個星雲光點浮動（代表九世）
- 頭頂有巨大圓環，八個黯淡、一個微亮
- 光點環繞如同星塵

## 境界修煉外觀變化

| 境界 | 典型外觀變化 |
|------|------------|
| 感氣期（初期） | 普通人外貌，無靈力波動外觀 |
| 聚元期 | 眼神開始清明，體魄強健 |
| 築基期 | 穩重沉靜，氣息綿長 |
| 煉魂期（當前） | 眼神深不見底，周身隱有魂力波動 |
| 凝神期（未來） | 神識強大，目光如炬 |

## 關鍵道具

- **塵淵劍**：漆黑劍鞘，銀白劍身，蘊含九世輪迴之力
- **雲塵印**、**凝元鎮塵印**：手掌大小的古印，平時藏於胸前
- **金色碎片**：封印之力凝聚，光芒內斂
- **螺旋符文**：融合時之碎片與空之碎片，平時隱於眉心

---

## 性格特徵

- **沉默寡言**：不擅言語，但意志極為堅定
- **內心戲豐富**：對九世真相充滿疑惑與使命感
- **恩怨分明**：被葉家當初放棄他銘記，但非狹隘報復
- **重視同伴**：對秦昭陽等戰友有深厚信任
- **不輕易放棄**：即使被稱為廢物，三年間從未停止修煉

## subject_reference 使用方式

每次生成新場景時：

1. **首次墊圖**：用「識海輪迴 prompt」或「日常修士 prompt」生成一張，作為 subject_reference
2. **後續生成**：在同一請求中加入 `subject_reference`：
   ```json
   {
     "model": "image-01",
     "prompt": "[場景描述]，葉塵，[其他角色]，...",
     "aspect_ratio": "16:9",
     "subject_reference": [
       {
         "type": "character",
         "image_file": "https://.../葉塵_base.png"
       }
     ]
   }
   ```
3. **墊圖要求**：上傳單人正面照，效果最好
