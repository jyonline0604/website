
## 17:10 中午簡報 — Cron 模型路由故障修復 <!-- project: github.com/jyonline0604/website -->
- 症狀：5 個 OpenClaw cron（早上簡報 08:15、中午簡報 12:55、每日 Audio Sync 10:00、每日健康報告 22:00、傍晚簡報 17:55）全部 consecutiveErrors>=1，錯誤 = "Automation candidate is incompatible with its recorded inference account and route."
- 根因：payload.model override 寫成 `minimax/MiniMax-M3.1-Flash@minimax:cn`，@`minimax:cn` 係 account 選擇 suffix，同 gateway 實際 routing 對唔上，preflight 直接拒絕（舊 2026-10-21 同類問題：override 唔喺 modelPolicy.allow）。
- 證據：無 override 嘅 job（heartbeat、Memory Dreaming）同 agent 預設 primary `minimax/MiniMax-M3.1-Flash` 全部正常；modelPolicy.allow 已同時包含兩種寫法，所以唔係 allow-list 問題，係 account/route suffix 問題。
- 修復：`openclaw cron edit <id> --model minimax/MiniMax-M3.1-Flash`（移除 @minimax:cn suffix），5 個 job 全部改用 gateway 預設 route。
- 教訓：cron job model override 唔好加 account suffix，用 agent 預設 model 名即可；preflight 錯 "incompatible with recorded inference account and route" = override route 失效，唔係 message/timeout 問題。
