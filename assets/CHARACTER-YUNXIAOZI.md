# 雲霄子 - 角色設定卡

## 人物外貌（固定描述）

```
Ancient Chinese Taoist scholar, silver-white long hair in topknot secured with jade pin,
wearing traditional flowing Taoist robe with subtle circuit pattern embroidery,
wearing strange optical goggles/visors on forehead, ethereal glowing appearance,
semi-transparent holographic form, wise and serene expression,
floating in a starry void, mystical cultivation tech aesthetic
```

## 人物背景

- **身份**: 三千年前修真文明的頂尖科學家、靈網時代創始人之一
- **存在形式**: 儲存在「靈網玉簡」中的意識信息備份（AI）
- **種族**: 人類（但具有超越時代的知識）
- **關鍵發明**: 靈網系統、靈芯理論、太初計劃核心架構師

## 重要劇情

### 與林塵的對話（108章）
林塵激活「靈網玉簡」後，雲霄子的意識信息備份覺醒，向林塵講述三千年前修真文明的高度發展歷程。

### 靈網時代
三千年前，修真文明達到頂峰：
- 修士在實驗室中研究靈氣本質
- 法寶內置智能導航系統
- 「靈網」將整個修真界的知識連成一體

### 大災變
敵人來自星空之外，使用扭曲現實的力量，導致靈網時代毀滅。敵人「沒有形體，沒有固定存在形式，像是現實的病毒」。

### 訊息遺產
在最後時刻，將靈網核心數據分散封存於數千枚「靈網玉簡」中。希望後人能重新發現，避免重蹈覆轍。
